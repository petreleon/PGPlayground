# SQL Basics — Interactive PostgreSQL Tutorial

Learn SQL by doing. An interactive tutorial that covers table creation, altering, keys, and constraints — all with a real PostgreSQL database running in your browser via [PGlite](https://pglite.dev).

## What You'll Learn

- **CREATE TABLE** — Define tables with columns, types, and constraints
- **Data Types** — INTEGER, VARCHAR, TEXT, NUMERIC, JSONB, and more
- **ALTER TABLE** — Add, rename, drop, and change column types
- **Primary Keys** — Create, add, and drop primary key constraints
- **Foreign Keys** — Link tables with referential integrity and CASCADE
- **DROP TABLE/Constraints** — Clean up and reset

## How It Works

PGlite compiles PostgreSQL to WebAssembly, so the database runs entirely in your browser — no servers, no installs. Your data persists in IndexedDB between sessions.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start the tutorial.
